Pixel art sprite sheet for an HD-2D game. The reference images show THREE characters, one per image, each as a strip of poses seen from the front. Draw THE SAME three characters: identical face, hair, outfit, colors, accessories, proportions, pixel density and dark outlines. Transparent background. A clean grid of 3 rows x 4 columns, one full-body figure per cell, centered, feet on the bottom of the cell, all figures the same height. Row 1 = the character of reference image 1, row 2 = reference image 2, row 3 = reference image 3. Columns, left to right: 1) side view walking to the RIGHT, left foot forward; 2) side view walking to the RIGHT, right foot forward; 3) back view seen from behind, walking away, left foot forward; 4) back view seen from behind, walking away, right foot forward. No text, no labels, no ground, no shadows.
